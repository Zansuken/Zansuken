### What I do

Four years at Vulog on a white-label B2B SaaS used by car-sharing operators across Europe. Card payments and wallets across two providers, a full subscription application built for two operator brands, and the internal Electron release tool the whole team uses every day.

Outside work I build and ship my own products. getfolio.dev is the current one, built and run solo.

### Selected work

#### [getfolio.dev](https://getfolio.dev)

Generates a developer portfolio from your GitHub activity and keeps it in sync. Auth, billing, custom domains with automatic HTTPS, eight themes over shared content, and an LLM review that scores a profile and rewrites the lines that weaken it. Solo across product, engineering, payments and infrastructure.

#### [doom-ui](https://github.com/Zansuken/doom-ui)

React and TypeScript component library built from scratch. Compound component patterns, headless architecture, zero dependencies. Includes an accessible DatePicker with range selection and a virtualized Table.

#### [agile-flow](https://github.com/Zansuken/agile-flow)

Full-stack project management app with a real-time Kanban board. React, NestJS, Firebase.
